# 每日例行（可选，默认关闭）

先手动用几次，确认在你的环境里登录稳定、价格读得准，再打开定时任务。

## 推荐的例行任务

| 时间 | 做什么 | 用户需要做什么 |
|---|---|---|
| 09:00 | 用官方 skill 领券，结果发给用户 | 不用做什么 |
| 11:00 / 17:30 | 检查登录态 → 读近期订单 → 发 2～3 个候选（选择题） | 回复选项 |
| 用户选好以后 | 组车 → 勾红包 → 读回 → 等用户说“提交” → 提交 | 说“提交”，然后在手机上付款 |

## 例行任务的护栏

- **开始前先检查登录态。** 过期了就通知用户“需要重新登录”，不能悄悄失败，也不要自动反复重试。
- **定时任务只能推荐，不能自己提交。** 每一单都必须等用户回复。
- 用户没回复就什么也不做，不要追着发消息。
- 用户说“今天不点”或“这周暂停”，记下来并照做。
